# Capacity Connect

## Project Overview

Capacity Connect is a digital capacity-building and learning management portal designed for the Ministry of Earth Sciences (MoES). It aims to support organizational training, competency development, and knowledge sharing through a centralized digital platform.

## Features

- Role-based portal for Trainees, Trainers, and Administrators.
- Dashboard for training and learning activities.
- Centralized learning and knowledge-sharing resources.
- Support for competency development.
- Learning support for Weather Forecasting, Radar Operations, Satellite Meteorology, Climate Science, and Disaster Management.
- User-friendly web interface.

## Technologies Used

- React
- JavaScript / TypeScript
- HTML and CSS
- Vite
- Node.js and npm

## Project Structure

The project contains the frontend application, configuration files, and related resources required to run the portal.

## Installation

### 1. Install Node.js

Install Node.js and verify that Node.js and npm are available.

### 2. Open the project folder

Open the Capacity Connect project folder in Visual Studio Code.

### 3. Install dependencies

Run this command in the terminal:

```bash
npm install
```

### 4. Run the application

```bash
npm run dev
```

### 5. Open the website

http://localhost:3000

## How to Use

1. Open the Capacity Connect website.
2. Explore the dashboard and navigation menu.
3. Access the available portal sections.
4. Use the features supported by the current implementation.

## Important Notes

- Keep the development server running while using the website.
- The local website address works on your computer while the server is running.
- Backend features require a separately configured backend, if applicable.
- Never upload API keys or passwords to a public repository.
